La navigation par intentions

Quatre verbes remplacent les noms de tables : Découvrir, Analyser, Construire, Espace de travail. Chaque menu est court, chaque entrée porte sa description d'une ligne, chaque porte future porte sa date — aucune porte cachée, aucune porte qui ment.

Accompagne docs/architecture-site.md. Les adresses existantes ne bougent pas ; seuls les libellés de menus se réorganisent. Persona entre parenthèses sous chaque intention (règle §9).
